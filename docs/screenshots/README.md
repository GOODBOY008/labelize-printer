# Screenshot provenance

These are native macOS screenshots of Labelize Studio, captured on 2026-11-12 from development commit `7155d05b790cf7d8b67acde086f39ee8d9229325`. The app ran in a separate bundle with a private data directory at a 1280 × 800 logical viewport. Captures are 2560 × 1600 JPEGs, saved directly from the desktop tool without retouching or recompression.

| Image | View and sample |
| --- | --- |
| `designer.jpg` | Visual designer displaying the [showcase template](../../examples/designer-showcase.labelize.json), its object catalog, layers and native PDF settings. |
| `workspace.jpg` | File workspace displaying [shipping-demo.zpl](../../examples/shipping-demo.zpl): one 102 × 152 mm page and one 75 × 50 mm page at 8 dpmm. |

All label content is synthetic demonstration data. The sample shipping label is not valid postage. The output path belongs to the isolated demonstration session.

The refreshed logo and Antialias/Vector controls shown here ship in v0.5.0. The macOS window-sharing indicator and pointer, where present, come from the capture environment.
